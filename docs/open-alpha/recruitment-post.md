# Open Alpha recruitment post

Use or adapt the text below only after the verified GitHub prerelease is available.

> **Relay Open Alpha: test structured project handoffs between AI coding clients**
>
> Relay is a local-first MCP service for explicit, auditable project-context handoffs. It stores a
> structured capsule that you deliberately submit; it does not read chat history, synchronize
> hidden memory, control coding agents, or run repository commands.
>
> We are looking for 10–20 Windows developers who already use two MCP-capable AI clients and can
> spend about 20–30 minutes testing one real handoff. The Alpha uses local SQLite and a local
> development credential. There is no hosted service and no product telemetry.
>
> This is experimental software, not a production-ready Public Beta. Please use synthetic or
> non-confidential project context. Setup requires Node.js 24 and pnpm 11.
>
> Read the Open Alpha overview and apply through the repository's structured application form:
> https://github.com/rohan-mokashi/relay
